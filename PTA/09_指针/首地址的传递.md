把数组传给函数时，传过去的不是整个数组的副本。数组表达式通常会转换为指向首元素的指针；函数拿到指针后，可以访问、修改原数组。若只传 `a[0][0]`，那传的是一个整数值。二维数组的首元素是**一整行**，这一点尤其容易弄混。

假设 `int a[m][n]`，下面四种写法的地址数值可能相同，类型却分成两组：

1. `a`：作为函数实参时转换为 `int (*)[n]`，指向第 0 行。
2. `&a[0]`：类型也是 `int (*)[n]`，同样指向第 0 行。
3. `&a[0][0]`：类型是 `int *`，指向第 0 行第 0 列的元素。
4. `a[0]`：作为实参时转换为 `int *`，指向第 0 行的首元素。

要让形参与实参的指针类型匹配。下面是一个**类型不匹配**的例子：
```
#include <stdio.h>

// 接收二维数组：matrix 指向一行，每行有 3 个 int
void printMatrix(int (*matrix)[3], int rows) {
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < 3; j++) {
            printf("%d ", matrix[i][j]); // 正确访问二维数组
        }
        printf("\n");
    }
}

int main() {
    int a[2][3] = {{1, 2, 3}, {4, 5, 6}};
    int *ptr = &a[0][0]; // ptr 指向首个 int，不是指向一行

    // 错误：函数需要 int (*)[3]，传入的却是 int *
    printMatrix(ptr, 2); // 编译器应给出类型不匹配的诊断

    return 0;
}
```

`matrix[i][j]` 需要知道每行有 `3` 个元素，才能按行移动。传 `a` 或 `&a[0]` 才与这里的形参匹配；传 `a[0]` 或 `&a[0][0]`，类型就变成了 `int *`。编译器需要给出诊断，具体是警告还是直接停止编译取决于设置。第 19 题里的 `scores` 也按这个规则判断。

---
#### 怎么匹配？
若实参是 `a` 或 `&a[0]`，形参可写 `void function(int (*arr)[N])`，也可写 `void function(int arr[][N])`。这里要给出列数 `N`，因为访问下一行时要用到它。

若实参是 `a[0]` 或 `&a[0][0]`，对应的形参是 `void function(int *arr)`。两种指针不能只因为地址数值相同就混用。
