## 程序设计基础（C语言）

> [!NOTE]
> 1. 部分实验由智能体协助编写，代码仅供参考
> 2. 仓库内题目可能过时，考试题目由系统随机抽取

## 目录导航

| 目录 | 内容 |
| --- | --- |
| [`EXP/`](EXP/) | 《程序设计基础实验指导》题解，按 `4.x` 小节组织 |
| [`PTA/`](PTA/) | PTA 练习与上机考试题解，按专题和考试批次组织 |

`EXP/` 保留指导书的小节编号；`PTA/` 保留题目分组编号。

## 编译与运行

每个 `.c` 文件通常对应一道独立题目。例如在仓库根目录运行：

```bash
cc PTA/01_平台熟悉/1.c -o /tmp/cxsjjc-example
/tmp/cxsjjc-example
```
